# SHADOW POINT ステージエディター（試作版）

## 起動方法
`stage-editor.html` をブラウザで開きます。Node.jsやサーバーは不要です。

## できること
- 現行ゲームと同じワールド座標（初期値 4800×912、グリッド12）
- 壁・奈落・塗装不可床の長方形配置
- 複数の得点エリア配置と個別得点の設定（右側の数値欄から編集）
- オブジェクトの選択、移動、数値編集、削除、1手戻す
- JSONのダウンロードと再読み込み

## ゲーム本体との接続について
JSONには `format: "shadow-point-stage"`、`world`、`rule`、`objects`、`areas` を保存します。
現在のゲームサーバーは `server.js` 内でオブジェクトを固定定義し、エリア争奪戦も単一の円形エリアを前提にしています。
したがって、このエディターが作成したJSONをゲームで使うには、次の開発段階でサーバー側にステージJSONの読み込み処理を追加し、複数エリアの占有・得点処理を実装する必要があります。このZIPでは既存ゲーム本体を変更していません。
