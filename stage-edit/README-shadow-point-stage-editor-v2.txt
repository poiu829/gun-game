SHADOW POINT ステージエディター v2

1. shadow-point-stage-editor-v2.html をブラウザで開きます。
2. 「通常ルール」「エリア争奪戦」を切り替えて、それぞれの配置を編集します。
3. 「一覧に保存」を押すと、ステージがこのブラウザのローカルストレージに保存されます。
4. 「ステージJSONをダウンロード」で、既存 server.js が読み込める JSON を保存します。
5. ダウンロードした JSON をサーバー側の stages/ フォルダに置いてください。1ステージにつき1つの JSON ファイルです。

JSON形式：
{
  "id": "stage1",
  "name": "ステージ名",
  "description": "説明",
  "rules": {
    "standard": { "objects": [] },
    "area": { "objects": [] }
  }
}

注意：このツールはブラウザ内の編集・保存ツールです。サーバー上のファイルを直接変更するものではありません。ゲームに反映するには、ダウンロードしたJSONをサーバーの stages/ フォルダに追加・置換してください。ステージIDはゲーム内で識別に使うため、既存ステージと重複しないようにしてください。
